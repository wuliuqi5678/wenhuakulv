# 300 本书介绍重写规范

目标：把每本书的 `intro` 改写成 **4–6 段**、内容更丰富、段与段不重复的中文介绍。不是把原段落换同义词，也不是把原段落合并。

## 输入

- `public/data/books.json`：当前 300 本书数据，`intro` 是旧介绍，`why`、`tags`、`genre`、`quotes` 可参考。
- `data/intro-rewrite/batches.json`：12 个批次，每批 25 本；只处理分配给你的那一批。
- 只修改/创建你这一批的 `data/intro-rewrite/batch-NN.json`，**不要改 `books.json`**，也不要碰其他批次文件。

## 每本写什么

优先从这些角度里选 4–6 个，保证每段都有新信息：

1. **故事/设定**：时间、地点、核心事件、开场处境。
2. **人物/冲突**：谁和谁冲突，想要什么，卡在哪里。
3. **写法/结构**：叙述视角、语言、讽刺/抒情/寓言方式、章节或结构特点。
4. **文学史位置**：作者创作阶段、与作者其他作品的关系、题材/流派上的意义。
5. **读法/难点**：读者容易忽略的细节、值得对读的作品、理解这本书的一把钥匙。

不要每本都机械套“情节—人物—写法—意义”四段；按书的特点调整。比如散文集写题材与语言，话剧写舞台冲突，科幻写设定与问题意识。

## 事实边界

- **以现有 `intro` 里的事实为基础**；可以重组、压缩、改写，但不要为了“丰富”编造具体出版年、版本、奖项、销量、销量排名、影视改编、真实人物经历。
- 不确定的精确事实不要写；把篇幅用在文本内的情节、人物、主题、语言和写法上。
- 不要复制其他书的段落，也不要把作者生平套话重复到每本书。
- 涉及真实历史/人物时保持克制，不写没有把握的指控或数字。

## 去重规则

- 同一本书内，任意两段不能是同一件事的改写/缩写/扩写。
- 不要用“换句话说”“也就是说”“这正是……”把上一段再说一遍。
- 不要用合并句来制造长度：如果一句话和前面重复，删掉它，补新角度。
- 尽量不重复同一个核心句；每段至少有一个前文没有的信息点。
- 目标总长度约 300–550 个汉字；4 段可以，5 段更好，最多 6 段。

## 输出格式

写入 `data/intro-rewrite/batch-NN.json`，内容是一个 JSON 对象：

```json
{
  "book-id-1": ["第一段", "第二段", "第三段", "第四段"],
  "book-id-2": ["第一段", "第二段", "第三段", "第四段", "第五段"]
}
```

- 必须是合法 JSON（UTF-8、双引号、不要 Markdown 代码围栏）。
- 必须覆盖分配批次里的 **全部 25 个 id**，不能多也不能少。
- 每段 2–4 句；不要空段；不要以“这本书”开头写每一段。
- 不要输出解释、前言、后记，只写 JSON 文件。

## 风格样例

这是《老张的哲学》已重写的样子（4 段，供参考，不要照抄到别的书）：

1. 1925 年，老舍在伦敦东方学院教书时写下这部长篇；1926 年 7 月起在《小说月报》连载，1928 年由商务印书馆出版。郑振铎在编后记里说，这种讽刺情调是当时的作家还没有弹奏过的。
2. 故事发生在二十年代前后的北京。老张（张明德）办学堂、收学费、放高利贷，连学生的婚事也要插一手；为了钱，他拆散两对青年男女的爱情，学生、家长、同行都被他拿捏。
3. 老舍不把老张写成青面獠牙的恶棍，而写成一个会讲理、会装体面、处处能自圆其说的“体面人”。满口哲学与满肚子算计之间的落差，既是笑料，也是小说的锋利处。
4. 这是老舍的初试啼声：结构还松，笔力却已经露出后来《离婚》《骆驼祥子》里的北京口语、人物漫画和悲悯。读它，既能看一个坏校长怎样算计，也能看一个年轻作家怎样找到自己的声音。

## 完成前自检

- 25 个 id 全部覆盖。
- 每本 4–6 段，总字数大约 300–550。
- 段内没有重复句/同义复述；快速通读一遍，确认不是把同一段拆成两段。
- JSON 能 `JSON.parse`。
- 只写了自己的 batch 文件。
